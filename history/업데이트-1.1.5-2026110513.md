## 📌 주요 업데이트 및 버그 수정

### 1. 🎙️ 저장한 성우 음성 및 복제 음성 생성 시 크래시 오류 수정
* **문제 원인**:
  * 기본 음성(Basic Voice)은 텍스트 프롬프트 기반으로 정상 생성되었으나, **저장한 성우 음성(Ai성우 - 여성/남성)** 또는 **내 목소리**를 선택하고 음성을 생성할 때 앱이 오류와 함께 중단되는 문제 발생.
  * 복제 모드(`reference_wav_path`) 실행 시 AI 엔진 내부(`VoxCPM2Model._encode_wav`)에서 오디오 디코딩을 위해 `librosa.load`를 호출하는데, `librosa` 내부의 `scipy.signal` 모듈 로드 시 내장 바이너리(`_spropack.cpython-310-darwin.so`)의 Mach-O 섹션 헤더(`section '__DATA/__thread_bss' has a zero-fill section type, but offset field is not zero`)가 최신 macOS dyld 링커와 충돌하여 `ImportError: dlopen`이 발생하던 현상 규명.
* **해결 조치**:
  * 불안정한 `librosa/scipy` 의존성을 완전히 제거하고, 무결하게 동작하는 **`soundfile` + `torchaudio.transforms.Resample`** 기반의 고속 네이티브 오디오 로더 파이프라인으로 전면 개편.
  * 백엔드 엔진([app.py](file:///Users/creatorjoseph/Desktop/code/Sori-Dam/app.py))의 모델 로드 단계에도 런타임 몽키패치를 이중 적용하여, 패키지 재설치나 환경 변화 시에도 충돌이 재발하지 않도록 견고한 방어 체계 구축.

### 2. 🛡️ 참조 음성 경로 해석 및 복사 안전 폴백(Fallback) 추가
* **상대/절대 경로 자동 감지**:
  * 음성 합성(`/api/generate`) 및 음성 보관함 저장(`/api/voices`) 시 작업 디렉터리(`VOXCPM_DATA_DIR`)와 파일시스템 CWD 간의 경로 차이로 인해 참조 파일이 누락되지 않도록 `VOICES_DIR`, `OUTPUTS_DIR`, `DATA_DIR` 후보 경로를 단계별로 자동 탐색하는 안전 폴백 탐색 로직 적용.
* **원본 파일 유실 방지**:
  * 생성 내역(`outputs`)에서 '내 음성으로 저장' 수행 시 원본 오디오 경로가 상대 경로로 전달되더라도 정확하게 원본을 탐색하여 보관함에 복사할 수 있도록 예외 방어 강화.

## 🛠️ 기술적 구현 사항

* **AI 엔진 (`voxcpm2.py`)**:
  * `_encode_wav`: `soundfile.read`로 스테레오/모노 오디오를 읽고 다채널 평균 모노 변환 후 `torchaudio.transforms.Resample`을 통해 모델 샘플 레이트(16kHz/24kHz)로 고속 리샘플링하도록 교체.
  * `_trim_audio_silence_vad`: `librosa` 호출 실패 시 안전하게 전체 구간을 유지하도록 예외 안전 처리.
* **백엔드 서버 (`app.py`)**:
  * `_patch_voxcpm_audio_loader()`: 모델 로드(`get_model`) 시 `VoxCPM2Model._encode_wav`를 동적으로 안전 로더로 치환하는 런타임 패치 구현.
  * `/api/generate`: `ref_p` 경로 탐색 시 `VOICES_DIR / ref_p.name` 및 `DATA_DIR / voice["audio_path"]` 폴백 추가.
  * `/api/voices`: `from_output_id` 복사 시 `OUTPUTS_DIR / src_path.name` 폴백 추가.
* **패키지 메타데이터**:
  * `package.json` 및 `package-lock.json` 버전 `1.1.4` → `1.1.5` 갱신.
