# 소리담 (Sori-Dam) v1.1.7 업데이트 내역

- **업데이트 일시**: 2026년 11월 5일 18시
- **버전**: `1.1.7` (이전 버전: `1.1.6`)
- **대상 플랫폼**: macOS (Apple Silicon M1~M4 / Intel Mac), Windows (NVIDIA CUDA / CPU 멀티스레드)

## 📌 주요 업데이트 내용

### 1. ⚡ 첫 음성 생성 시 실시간 AI 모델 로딩 안내창 & 진행바 탑재
* **배경 및 목적**:
  * 소리담 구동 후 최초 1회 음성을 생성할 때, 고품질 파운데이션 모델(VoxCPM2, 가중치 약 4.6GB)을 시스템 메모리에 로드하는 과정에서 시스템 사양에 따라 수십 초의 대기 시간이 발생합니다.
  * 막연히 기다리는 동안 앱이 멈춘 것처럼 느껴지는 불편을 해소하고, 로딩 현황을 명확히 인지할 수 있도록 입력창 하단에 실시간 진행 상태 안내 박스를 탑재했습니다.
* **주요 기능 및 UI**:
  * **전체/현재 로드 용량 실시간 표시**: `0.0 GB / 4.6 GB (MB 단위 병기)` 및 실시간 퍼센티지(%) 안내.
  * **진행 애니메이션 게이지바**: safetensors 가중치 적재 진행 상황에 맞추어 부드럽게 상승하는 프로그레스 바.
  * **상세 상태 메시지 및 장치 태그**: 현재 단계("오디오 VAE 로드 중", "신경망 디코더 로드 중" 등)와 구동 장치(Apple Silicon MPS / CUDA GPU / CPU) 실시간 표시.
  * **스마트 자동 숨김**: 모델 로드가 완료되면 1.2초 후 자연스럽게 사라지며 즉시 음성 합성을 이어 진행.
  * **이후 즉시 생성**: 모델이 메모리에 상주하는 두 번째 생성부터는 해당 박스가 뜨지 않고 바로 생성됩니다.

### 2. 🎨 운영체제 간 UI 일관성을 위한 SVG 벡터 아이콘 전면 교체
* **배경 및 목적**:
  * macOS, Windows 등 OS 버전과 폰트 렌더러에 따라 모양, 색상, 정렬이 다르게 보이던 모든 이모지(Emoji)를 정밀 SVG 벡터 아이콘으로 교체했습니다.
* **적용 내역**:
  * 사이드바, 헤더 제어 버튼, 웰컴 온보딩 모달, 개인정보처리방침 모달, 사전 설치 마법사, 캐릭터(소리담이) 대화창 및 로그창 전반에 일관되고 미려한 모던 SVG 아이콘 적용.

### 3. 🎙️ 첫 실행 안내 가이드(온보딩 팝업) 및 재설치 경험 개선
* **온보딩 안내 고도화**:
  * 소리담의 독창적인 AI 성우 제작 방식(스타일 텍스트 지정 생성 및 사용자 음성 복제), 첫 로딩 시간 안내, 100% 무료 오픈소스 라이선스 명시.
* **설정 영속성 정밀화**:
  * `다시 보지 않기` 체크박스 상태를 명확히 분리하여, 체크하지 않고 닫은 경우 재실행 시 지속 안내되며, 체크한 경우에만 안전하게 스킵되도록 개선.
  * 상단 헤더 우측의 `?` 버튼을 통해 언제든 온보딩 가이드를 다시 열람 가능.

### 4. 🛡️ 사이드바 개인정보처리방침 안내 버튼 및 모달 탑재
* **100% 로컬 프라이버시 보장**:
  * 사이드바 하단 후원 버튼 아래 `개인정보처리방침` 버튼을 추가.
  * 외부 서버 전송이 전혀 없는 100% 온디바이스 독립 구동과 데이터 보관/삭제 권리를 명시하는 카드형 안내 모달 제공.

### 5. 🛠️ 음성 생성 안정성 강화 및 오류 방어 로직
* **스크립트 스코프 오류 수정**: 전역 스코프 호이스팅 및 바인딩을 정비하여 첫 생성 시 발생하던 스크립트 중단 현상을 원천 차단.
* **예외 핸들링 강화**: `handleGenerate()` 함수 전반에 걸친 예외 방어 및 버튼 상태 복구 로직 추가.
* **SSE 로그 큐 스레드 안전성 보강**: 백엔드 로그 브로드캐스트 재진입 방지 플래그 및 동적 큐 보장을 통해 실시간 로그 전송 신뢰성 향상.

## 🛠️ 기술적 구현 사항

* **백엔드 (`app.py`)**:
  * `_patch_safetensors_loader()`: 모델 가중치 파일 로딩 시 실시간 바이트/진행률 콜백 후킹 구현.
  * `_TeeBroadcastStream` 재진입 방지(`_in_write`) 플래그 적용 및 비동기 이벤트 루프 안전 큐(`_get_queue`) 개선.
  * `/api/generate` 엔드포인트 내 `[MODEL_PROGRESS]` SSE 이벤트 브로드캐스트 연동.
* **프론트엔드 (`static/app.js`, `static/index.html`, `static/style.css`, `static/i18n.js`)**:
  * `#modelLoadingProgressBox` UI 마크업, 게이지 애니메이션 및 다국어 번역 키(`create.modelLoading*`) 추가.
  * `EventSource` 메시지 핸들러 내 모델 로딩 진행률 실시간 반영 로직 구현.
  * 모든 이모지 요소를 SVG 코드로 표준화.
* **일렉트론 및 패키징 (`electron/main.js`, `package.json`, `package-lock.json`)**:
  * 렌더러 콘솔 메시지 자동 포워딩 리스너 추가(`webContents.on('console-message')`).
  * 앱 버전 `1.1.6` → `1.1.7` 갱신.
