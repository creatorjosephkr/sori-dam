# 소리담 (Sori-Dam) v1.1.3 업데이트 내역

- **업데이트 일시**: 2026년 11월 4일 20시
- **버전**: `1.1.3` (이전 버전: `1.1.0`)
- **대상 플랫폼**: macOS Apple Silicon (arm64), Windows (x64)

## 📌 주요 업데이트 및 변경 사항

### 1. Apple Silicon (M1/M2/M3/M4) "손상된 파일" 실행 오류 해결
* **문제 원인**:
  * macOS ARM64 커널의 엄격한 바이너리 무결성 검증 정책으로 인해, 번들 패키징 시 서명이 일치하지 않거나 누락된 경우 "손상된 파일이라며 열 수 없습니다. 휴지통으로 이동해야 합니다" 경고창과 함께 실행이 차단되는 문제 발생.
* **해결 조치**:
  * `scripts/after-pack.js` 빌드 훅 스크립트 신규 추가.
  * DMG 패키징 직전(`afterPack` 단계)에 `Sori-Dam.app` 전체 번들 및 내장 파이썬 환경(`bin/python-mac-arm64`), 공유 라이브러리(`.dylib`, `.so`)를 빠짐없이 Ad-hoc 심층 서명(`codesign --force --deep -s -`)하도록 파이프라인 구축.
  * 서명 유효성 검증(`codesign --verify` 및 `spctl --assess`) 통과 완료.

### 2. 빌드 및 서명 파이프라인 안정화
* **인증서 템플릿 정리**: `package.json`의 더미 인증서(`Developer ID Application: YOUR_NAME (TEAMID)`) 제거 및 로컬 빌드 최적화.
* **공증(Notarize) 스크립트 예외 처리**: `scripts/notarize.js`에서 Apple ID 자격 증명이 없는 로컬 환경 빌드 시 빌드가 중단되지 않고 안전하게 건너뛰도록 방어 코드 추가.

### 3. 버전 업데이트
* `package.json` 및 `package-lock.json` 버전 `1.1.0` → `1.1.3` 갱신.

## 💡 macOS 설치 및 최초 실행 안내

1. 다운로드한 `Sori-Dam-1.1.3-arm64.dmg`를 열고 `Sori-Dam`을 `Applications(응용 프로그램)` 폴더로 복사합니다.
2. 최초 실행 시 게이트키퍼(Gatekeeper) 보안 경고가 발생할 경우, 터미널에서 다음 명령어를 실행하여 격리 속성을 해제합니다:
   ```bash
   xattr -cr /Applications/Sori-Dam.app
   ```
   또는 **시스템 설정 → 개인정보 보호 및 보안 → "확인 없이 열기"**를 클릭합니다.
