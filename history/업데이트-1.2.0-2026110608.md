# 업데이트 내역 - v1.2.0 (2026-11-06 08시)

## 1. 개요
- **버전**: `1.1.8` → `1.2.0`
- **핵심 변경 사항**: 깃허브 저장소(`creatorjosephkr/sori-dam`) 기반 생성 음성 공유(Export) 및 가져오기(Import) 기능 기획 및 구현

## 2. 세부 구현 내역

### 백엔드 (`app.py`, `shared_voices/`)
1. **공유 저장소 디렉터리 및 GitHub 단일 진실 공급원(Single Source of Truth) 동기화 (`shared_voices/`)**:
   - `shared_voices/index.json` 메타데이터 인덱스를 GitHub 원격 저장소(`creatorjosephkr/sori-dam`) 기준으로 실시간 동기화하며, 로컬 미업로드 항목이 섞이지 않도록 원격 인덱스 기준으로 로컬 캐시/번들을 갱신
2. **DB 스키마 자동 마이그레이션 (`migrate_db`)**:
   - `voices` 테이블에 `shared_id TEXT DEFAULT ''` 컬럼을 추가하여 공유 저장소에서 가져온 음성의 중복 다운로드 방지 및 가져오기 상태(`imported`) 추적 지원
3. **공유 저장소 REST API 추가**:
   - `GET /api/shared-voices`: GitHub Contents API / Raw URL을 통해 원격 저장소에 실제 공유된 음성 목록을 실시간 반환 (오프라인 시에만 로컬 캐시 폴백)
   - `GET /api/shared-voices/{shared_id}/audio`: 공유 음성 샘플 미리듣기 오디오 스트리밍 및 로컬 캐싱(`data/shared_cache/`)
   - `POST /api/shared-voices/import`: 선택한 공유 음성을 다운로드하고 길이 정규화(3초 이상 보장) 후 로컬 `voices` 테이블에 자동 등록
   - `POST /api/shared-voices/export`: 생성 기록(`from_output_id`) 또는 내 음성(`from_voice_id`)의 오디오와 메타데이터를 GitHub REST API(`PUT /repos/creatorjosephkr/sori-dam/contents/shared_voices/...`) 및 로컬 Git 동기화를 통해 업로드
   - `GET /api/shared-voices/auth-status`, `POST /api/shared-voices/token`: GitHub 업로드 인증 상태 확인 및 토큰 저장(`data/github_config.json`)

### 프론트엔드 (`static/index.html`, `static/app.js`, `static/i18n.js`)
1. **음성 만들기 화면 (`#page-create`)**:
   - `기본 음성` / `내 음성` / `공유 저장소` 3단 탭 구성 및 `공유저장소 목록 · 선택` 모달 추가
   - 공유 음성 선택 시 자동 Import 및 스타일·고급 설정(CFG, 단계, 볼륨, 속도) 자동 바인딩
2. **생성 기록 화면 (`#page-history`)**:
   - 각 생성 기록 아이템에 `공유저장소 공유하기` 버튼 및 업로드 모달 추가
3. **내 음성 관리 화면 (`#page-voices`)**:
   - `공유저장소 음성 가져오기` 버튼 및 `공유 저장소` 탭 추가 (성별 필터, 샘플 미리듣기, PC에 저장, 원클릭 가져오기, 바로 사용하기 지원)
   - 기존 내 음성 카드(`내 목소리`, `Ai성우 - 여성`, `Ai성우 - 남성`)에 **`PC에 저장`** 버튼(`downloadVoiceToPC`, `{성우이름}.wav` 다운로드) 및 **`공유저장소 공유`** 버튼 추가
4. **사이드바 후원 아이콘 단순화 및 통합 후원 모달 개편 (`static/index.html`, `static/style.css`, `static/app.js`, `spon/`)**:
   - 좌측 사이드바 하단 후원 영역을 `/spon/spon.svg` 단일 아이콘 버튼(`.btn-spon-single`)으로 단순화
   - 클릭 시 상단에 귀여운 캐릭터(`#donateDamiMascot`)와 말풍선(`#donateDamiSpeech`)을 배치하고, 하단 좌측에 카카오뱅크 QR(`/spon/kakaobank.png`), 우측에 클릭 시 시스템 기본 웹브라우저로 열리는 PayPal 로고(`/spon/paypal.svg`)를 나란히 배치한 통합 후원 모달(`#donateKakaoModal`) 구현
