- **업데이트 일시**: 2026년 11월 4일 23시
- **버전**: `1.1.4` (이전 버전: `1.1.3`)
- **대상 플랫폼**: macOS (Apple Silicon M1~M4 / Intel Mac), Windows (NVIDIA CUDA / CPU 멀티스레드)

## 📌 주요 업데이트 및 신규 기능

### 1. 전 기종 범용 하드웨어 가속 자동 감지 및 최적화 엔진
* **배경 및 목적**:
  * 특정 칩셋(예: M3)으로 고정되어 있던 하드웨어 점검 로직을 완전히 제거하고, **Apple Silicon(M1, M2, M3, M4 등 전 세대), Intel Mac, Windows (NVIDIA CUDA 및 고성능 멀티스레드 CPU)** 등 사용자의 실제 기기 스펙을 실시간 정밀 감지하도록 전면 개편.
* **플랫폼별 맞춤 가속 지원**:
  * **Apple Silicon Mac (M1~M4)**: `sysctl` 기반 실제 프로세서 식별 (예: `Apple M4 MPS`) 및 Metal Performance Shaders(MPS) 뉴럴 가속 자동 매핑.
  * **Intel Mac**: CPU 멀티스레드 코어 감지 및 PyTorch 스레드 최적화 자동 적용.
  * **Windows (NVIDIA)**: CUDA 코어 및 텐서 가속 디바이스 실시간 감지 (예: `CUDA: RTX 4070`).
  * **Windows (기본 CPU)**: 프로세서 식별자 및 가용 논리 코어 멀티스레드 최적화.
* **동적 UI 및 안내 문구**:
  * 화면 상단 뱃지, 사전 설치 마법사, 캐릭터 대사, 진행 상태 태그에 실제 감지된 칩셋 이름(예: `Apple M4 MPS`, `NVIDIA CUDA`, `CPU 16코어`)이 실시간 반영.

### 2. 첫 실행 AI 모델(VoxCPM2) 사전 설치 마법사 도입
* **배경 및 목적**:
  * 첫 설치 후 최초 음성 생성 시 대용량 모델(약 4.6GB) 다운로드 및 하드웨어 가속 컴파일로 인해 수 분간 멈추는 현상(첫 생성 지연)을 완전히 해소.
  * 앱 최초 실행 시 모델 설치 상태를 자동 진단하고, 사전 설치 여부를 친절히 묻는 온보딩 창을 제공하여 사용자가 미리 모든 요소를 완비할 수 있도록 개선.
* **주요 구성**:
  * **사전 설치 권장 안내 팝업**: 첫 음성 생성 지연 제로, 하드웨어 가속 최적화, 100% 완전 오프라인 구동 등 3대 혜택 소개 및 [지금 바로 사전 설치(권장)] / [나중에 하기] 선택권 제공.
  * **언제든 재실행 가능**: 상단 헤더에 `AI 준비됨 / 사전 설치` 상태 표시 뱃지 및 음성 만들기 화면 상단 안내 배너 추가.

### 3. 시각적 진행 상태 인디케이터 및 실시간 진행률
* **4단계 진행 프로세스**:
  1. `가속 점검`: 내 컴퓨터의 하드웨어 가속 엔진(Apple Silicon / NVIDIA CUDA / CPU) 실시간 감지 및 검증
  2. `모델 다운로드`: Hugging Face Hub에서 4.6GB 가중치 다운로드 (실시간 % 및 MB/s 속도, 다운로드된 용량/전체 용량 표시, 로컬 캐시 존재 시 자동 패스)
  3. `가속 웜업 & 로드`: 신경망 모델 메모리 적재 및 디바이스 커널 사전 컴파일/워밍업
  4. `준비 완료`: 설치 완료 즉시 대기 시간 없이 즉각적인 음성 생성 가능
* **0% 멈춤 현상 완전 해결**:
  * SVG 마스코트 캐릭터(`damiMascot`) 클래스 조작 시 브라우저 Strict 모드에서 발생하던 `SVGAnimatedString` 읽기 전용 속성 오류를 `setAttribute('class', ...)` 표준 방식으로 전면 수정.
  * SSE 연결 수립 즉시 초기 5% 반응 신호가 UI에 즉각 렌더링되도록 백엔드 큐 파이프라인 보강.
* **세부 로그 콘솔 토글**: 실시간 터미널 로그를 펼쳐볼 수 있는 토글 제공.

### 4. 귀여운 인터랙티브 마스코트 캐릭터 '소리담이' 애니메이션 추가
* **설치 대기 시간을 즐겁게 만드는 다채로운 모션 SVG 애니메이션**:
  * 🎧 **리듬 타기 & 음악 감상 모드**: 헤드폰을 끼고 리듬을 타며 무지개 음표가 퐁퐁 떠오르는 동작
  * 🔍 **탐색 모드**: 돋보기로 최적의 신경망 가속 경로를 찾는 동작
  * 📖 **공부 & 학습 모드**: 동그란 안경을 쓰고 AI 사전을 넘기며 머리 위 전구가 반짝이는 동작
  * 🎤 **노래 & 웜업 모드**: 마이크를 잡고 신나게 열창하며 바닥에 오디오 이퀄라이저가 춤추는 동작
  * 🎉 **축하 & 완성 모드**: 양팔을 번쩍 들고 방방 뛰며 반짝이 별과 콘페티 폭죽이 터지는 동작
* **재미있는 인터랙션**:
  * 캐릭터 클릭 시 콩콩 튀어 오르는 바운스(Squash & Stretch) 및 다정한 반응 대사 출력
  * 상황에 맞게 4~5초마다 부드럽게 바뀌는 따뜻하고 위트 있는 말풍선 가이드 멘트

### 5. 설치 DMG 볼륨 타이틀 및 앱 표시명 별칭(Alias) 한글화
* **DMG 설치 창 명칭 및 버전 표시**: DMG 파일을 더블클릭하여 마운트할 때 나타나는 볼륨 및 윈도우 타이틀을 기존 `VoxCPM2 음성 생성기`에서 현재 앱 버전이 함께 표기되는 **`소리담 1.1.4`** (`소리담 ${version}`)로 변경.
* **표시명 별칭(Alias) 기반 한글화 (`CFBundleDisplayName`)**:
  * 파일시스템 상의 실제 번들 디렉터리 명칭은 영문 `Sori-Dam.app`을 유지하여 포터블 파이썬 C-확장 모듈, dyld 로더, SQLite 경로 등의 UTF-8/NFD 인코딩 오류를 완벽히 예방.
  * macOS 표준 별칭(Alias) 아키텍처인 `CFBundleDisplayName = "소리담"`, `LSHasLocalizedDisplayName = true`, `ko.lproj/InfoPlist.strings`를 패키지에 자동 주입하여 Finder, Launchpad, Dock, 메뉴바 등 사용자 UI에서는 자연스럽게 **`소리담`**으로 표시되도록 구성.
* **데이터 자동 마이그레이션**: 이전 버전 데이터 폴더와의 호환을 위해 `~/Library/Application Support/` 내 데이터 무손실 동기화 처리.

## 🛠️ 기술적 구현 사항

* **백엔드 (`app.py`)**:
  * `get_hardware_info()`: macOS `sysctl`, Windows 환경 변수, PyTorch 가속 백엔드를 종합 분석하는 범용 하드웨어 감지 함수 구현
  * `GET /api/system/model-status`: Hugging Face Hub 캐시 및 메모리 적재 여부, 하드웨어 가속 타입 즉시 진단
  * `GET /api/system/pre-install/stream`: Server-Sent Events (SSE) 기반 실시간 진행률 및 캐릭터 동작 스트리밍 파이프라인
* **프론트엔드 (`static/`)**:
  * `index.html`: `preinstallModal`, `modelNoticeBanner`, `btnModelSetup` 헤더 버튼 마크업
  * `style.css`: 순수 SVG 및 CSS 키프레임 애니메이션으로 60fps 부드러운 캐릭터 모션 구현 (외부 리소스 의존 0%)
  * `app.js`: 온보딩 자동 트리거, 하드웨어 칩셋별 동적 대사 생성기(`getDamiQuotes`) 및 SSE 이벤트 연동 모듈
  * `i18n.js`: 한국어 및 영어 완벽 지원
