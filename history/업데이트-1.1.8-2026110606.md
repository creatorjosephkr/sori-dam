## 주요 업데이트 내용

### 1. Windows 설치 및 초기 기동 안정성 대폭 강화
* **배경 및 목적**:
  * Windows에서 `C:\Program Files\Sori-Dam` 경로에 설치할 경우 일반 사용자 권한으로 실행 시 내부 `site-packages`가 읽기 전용이 되어 런타임 패키지 설치 중 권한 거부(`exit status 1`)로 강제 종료되는 문제가 있었습니다.
  * 또한 사용자 PC의 기존 글로벌 Python(`%APPDATA%\Python`) 경로가 섞이거나, 런타임 `pip install voxcpm` 과정에서 호환성 패치가 덮어씌워져 `voxcpm` 임포트 오류가 발생하는 문제를 해결했습니다.
* **주요 개선 사항**:
  * **쓰기 가능한 전용 격리 환경 구축**: `%APPDATA%\sori-dam\data\python-user\Python310\site-packages` 경로를 전용 런타임 사이트 패키지로 지정(`PYTHONUSERBASE` 및 `--target`)하여 설치 경로와 무관하게 권한 오류 없이 패키지가 설치되도록 개선.
  * **기존 다운로드된 PyTorch 자동 이관**: 이전 실행에서 받아둔 `torch`/`torchaudio`가 있는 경우 재다운로드 없이 전용 격리 폴더로 즉시 이관.
  * **필수 패키지 사전 번들링 완료**: `voxcpm`(호환성 패치 적용본), `librosa`, `scipy`, `numba`, `llvmlite`, `soundfile`, `transformers`, `safetensors`, `sympy`, `mpmath`, `networkx`, `jinja2`, `MarkupSafe` 등 필수 의존성을 설치 파일 내에 사전 포함하여 초기 구동 속도 및 안정성 확보.

### 2. 저사양 Windows PC 및 구형 GPU 자동 감지·CPU 안전 폴백
* **배경 및 목적**:
  * VoxCPM2(약 4.6GB) 모델은 CUDA 가속 시 최소 5.5GB 이상의 VRAM과 Compute Capability 6.0 이상의 아키텍처가 필요합니다.
  * GTX 750 Ti(2GB VRAM, CC 5.0) 등 저용량 VRAM 또는 구형 그래픽카드 환경에서 무조건 CUDA 모드로 진입할 경우 대용량(2.5GB) 다운로드 지연 및 메모리 부족(OOM)·커널 오류가 발생하는 문제를 해결했습니다.
* **주요 개선 사항**:
  * **사양 맞춤형 PyTorch 설치**: `nvidia-smi`를 통해 VRAM(5.5GB 이상) 및 Compute Capability(6.0 이상)를 사전 점검하여, 기준 미만인 저사양 PC에서는 2.5GB CUDA 버전 대신 경량 CPU 최적화 PyTorch를 빠르게 설치.
  * **런타임 디바이스 및 dtype 자동 최적화**: 구형/저용량 GPU 감지 시 자동으로 CPU 멀티스레드(`float32`) 모드로 구동하며, `bfloat16` 미지원 CUDA GPU(Pascal/Turing 등)에서는 `float16`으로 자동 조정.
  * **CUDA 로드 예외 시 CPU 자동 재시도**: 모델 로드 중 CUDA 예외 발생 시 즉시 캐시를 비우고 CPU 모드로 재시도하여 중단 없는 실행 보장.

### 3. 기동 타임아웃 개선 및 버전 업데이트 다운로드 링크 수정
* **활동 기반 기동 대기 타이머**:
  * 최초 기동 시 대용량 모듈 설치 중 타임아웃이 발생하지 않도록 최대 대기 시간을 30분으로 연장하고, 표준 출력/에러 로그가 발생하는 동안 활성 타이머가 자동 갱신되도록 개선.
* **버전 업데이트 모달 외부 브라우저 연결 수정**:
  * 업데이트 알림창에서 `다운로드 페이지로 이동` 클릭 시 Electron IPC(`open-external`)를 통해 기본 브라우저에서 최신 GitHub 릴리즈 페이지가 정상적으로 열리도록 수정.

## 기술적 구현 사항

* **백엔드 (`app.py`, `voxcpm/model/utils.py`)**:
  * `_WIN_RUNTIME_SITE` 전용 격리 경로 설정, 글로벌 `%APPDATA%\Python` 경로 차단 및 기존 `torch` 자동 마이그레이션 구현.
  * `_WIN_BUNDLED_PACKAGES` 정의를 통해 사전 번들링된 패키지의 불필요한 `pip` 재설치 및 패치 덮어쓰기 방지.
  * `has_capable_nvidia_gpu()` 및 `can_use_cuda_for_voxcpm()` 함수를 통한 하드웨어 사양 판별 및 `get_model()` 내 CPU 자동 폴백 구현.
  * `pick_runtime_dtype()` 및 `auto_select_device()`에서 CPU `float32`, 구형 CUDA `float16`, 저사양 GPU CPU 전환 지원.
* **일렉트론 (`electron/main.js`, `electron/preload.js`, `static/app.js`)**:
  * `spawnPython`에서 `PYTHONUSERBASE`, `PYTHONUNBUFFERED=1` 설정 및 오염 환경변수(`PYTHONPATH`, `PYTHONHOME`, `PYTHONNOUSERSITE`) 초기화.
  * `waitForServer` 타임아웃 30분 연장 및 스트림 출력 기반 `lastActivity` 갱신.
  * `ipcMain.on('open-external')` 핸들러 추가 및 `preload.js` 연동.
* **패키징 (`package.json`, `package-lock.json`, `scripts/setup-binaries.js`)**:
  * Windows 사전 번들링 패키지 목록 동기화 및 버전 `1.1.7` → `1.1.8` 업데이트.
